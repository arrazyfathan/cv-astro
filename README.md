# Astro CV

An Astro + TypeScript + Tailwind CSS recreation of the original minimalist CV.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Cloudflare Pages

- Framework preset: `Astro`
- Build command: `npm run build`
- Build output directory: `dist`

The site is static and does not need a Cloudflare adapter.
